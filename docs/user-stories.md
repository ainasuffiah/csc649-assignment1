# Part B3: User Stories

### 1. As a patient, I want to check my queue status and estimated waiting time, so that I know when my turn is. (FR1, FR2)
**Acceptance Criteria**
1. The system displays the patient's queue number and current status.
2. The system shows the estimated waiting time for the patient.

### 2. As a clinic staff member, I want the system to arrange patients based on their priority levels and waiting time, so that patients can be attended according to their priority. (FR3, FR4)
**Acceptance Criteria**
1. The system calculates patient priority scores based on urgency level and waiting time.
2. The system assigns patients to an available consultation queue based on their priority scores.

### 3. As a clinic staff member, I want to manage doctor availability, so that patient queues can be updated when a doctor becomes unavailable. (FR5, FR10)
**Acceptance Criteria**
1. Clinic staff can update a doctor's availability status.
2. When a doctor becomes unavailable, the system updates the affected patient queue assignments.
